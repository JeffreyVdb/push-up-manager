# Bundled fonts

All faces are variable, latin-subset WOFF2 files, licensed under the
SIL Open Font License 1.1, and are embedded in the binary. Nothing is fetched
from a CDN at runtime.

| File | Family | Weights | Upstream |
|---|---|---|---|
| `bigshoulders.woff2` | Big Shoulders Display | 400–900 | https://fonts.google.com/specimen/Big+Shoulders+Display |
| `archivo.woff2` | Archivo | 400–800 | https://fonts.google.com/specimen/Archivo |
| `fraunces.woff2` | Fraunces | 400–700, optical size 9–144 | https://fonts.google.com/specimen/Fraunces |

Fraunces supplies the plant-based theme's headings and numerals. Its license
is bundled in `Fraunces-OFL.txt`. Big Shoulders remains the classic display face.
